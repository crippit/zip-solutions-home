# Zip Captions Companion Extension

<iframe width="560" height="315" src="https://www.youtube.com/embed/xMFm8ToDeU4?si=yghqvetmTaj_MltP" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

Acts as a bridge to allow Bitfocus Companion to send commands to and receive status from an open Zip Captions tab.

Add support for Bitfocus Companion with Zip Captions. 
This extension must be running on the same local computer as companion. 

This supports the following:
- Start/Stop
- Play/Pause
- Return Captioning Status to Companion
- Show last captioned word in Companion
